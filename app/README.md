# RPi Car Manual App

Landscape Expo client for the manual-only car controller.

```bash
npm install
npm run typecheck
npm run android
```

The app supports exclusive remote ownership, arm/disarm, F/N/R, proportional
spring-return throttle and steering, brake, e-stop, on-demand battery, and
steering calibration. Disarmed Wi-Fi/hotspot switching is included. It
intentionally has no telemetry or camera stream.

See the repository `MOBILE_APP_GUIDE.md` and `TRANSFER_CHECKLIST.md`.
